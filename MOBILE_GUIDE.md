# Установка AdBlockFilms на телефон

## Android

Обычный Google Chrome для Android не поддерживает установку сторонних расширений, но **AdBlockFilms** полностью работает в мобильных браузерах на базе Chromium с поддержкой расширений.

### Способ 1: Kiwi Browser (самый простой)

1. Установите **Kiwi Browser** из Google Play.
2. Скачайте на телефон архив **[AdBlockFilms-v1.0.0.zip](https://github.com/Stepan-Warriors/AdBlockFilms/raw/main/AdBlockFilms-v1.0.0.zip)**.
3. Откройте меню Kiwi Browser (`⋮` справа вверху) → **Extensions** (Расширения).
4. Включите **Developer mode** (Режим разработчика).
5. Нажмите кнопку **`+ (from .zip/.crx/.user.js)`**.
6. Выберите скачанный файл `AdBlockFilms-v1.0.0.zip`.
7. Готово — расширение появится в списке и сразу начнёт работать. Управлять им можно через меню `⋮` → **AdBlockFilms**.

### Способ 2: Lemur Browser или Mises Browser

1. Установите **Lemur Browser** или **Mises Browser** из Google Play.
2. Скачайте **[AdBlockFilms-v1.0.0.zip](https://github.com/Stepan-Warriors/AdBlockFilms/raw/main/AdBlockFilms-v1.0.0.zip)**.
3. Откройте страницу расширений в меню браузера и включите **Режим разработчика** (*Developer mode*).
4. Выберите загрузку из `.zip` (или распакуйте архив в папку и выберите **Load unpacked**).

---

## iPhone и iPad (iOS)

На iOS (iPhone / iPad) **расширения формата Chrome Manifest V3 не поддерживаются** ни в одном браузере (все браузеры на iOS работают на системном движке WebKit и позволяют ставить расширения только для Safari из App Store).
